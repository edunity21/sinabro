# 시나브로 넷

2026. 학교예술교육 실천사례 연구대회
「시의 품에 안긴 나, 브레인 AI와 로그인하다 – 시나브로 프로젝트」 연구보고서·요약서 웹페이지

주소: https://edunity21.github.io/sinabro/

## 폴더 구성

- `index.html` — 페이지 전체 (스타일·스크립트 포함)
- `img/main/` — 요약서·보고서 본문 사진 (82개)
- `img/appx1/`, `img/appx2/` — 부록 사진 (81개, 80개)

## 올리는 방법

1. `sinabro` 레포지터리의 Add file → Upload files 에서 `index.html`, `README.md`를 올립니다.
2. `img` 폴더는 웹 업로드가 한 번에 100개까지라서 `img/main`, `img/appx1`, `img/appx2` 폴더를 하나씩 끌어다 놓고 각각 Commit 합니다. 폴더 구조(`img/main/...`)가 그대로 유지되어야 사진이 보입니다.
3. Settings → Pages 에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)` 로 저장합니다.
4. 1~2분 뒤 https://edunity21.github.io/sinabro/ 에서 확인합니다.
